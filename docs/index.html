🔒

Private by default

Every check above runs locally, so your unpublished paper never leaves your machine. The only network call anywhere in the tool is an optional, keyless CrossRef title lookup. AcademicGuard does not integrate Turnitin, iThenticate, Copyscape, ZeroGPT, or GPTZero; run those separately for a final institutional check. See academicguard services for exactly what's active on your machine.

Quick start

CLI for interactive use, Python API for scripts and CI.

Install & run

# pip install
$ pip install academicguard
$ python -m spacy download en_core_web_sm

# analyze + save an HTML report
$ academicguard analyze paper.pdf \
    --venue ieee --html report.html

Python API

import academicguard.api as ag

report = ag.analyze(
    "paper.pdf", venue="ieee"
)
print(report.overall_label,
      report.overall_score)
report.save_html("report.html")
